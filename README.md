# هدهدك | HUDHUDAK — MVP 0.1

نسخة أولية قابلة للتشغيل من واجهة تطبيق حجز فنادق إيران للمستخدم العربي/العراقي.

## اجرا
1. Flutter SDK 3.3+ را نصب کنید.
2. در این پوشه اجرا کنید:
   flutter pub get
   flutter run

## نکته
این نسخه Prototype/MVP رابط کاربری است و هنوز به Backend، دیتابیس، پرداخت واقعی و API هتل‌ها متصل نیست.
